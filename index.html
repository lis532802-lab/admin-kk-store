Firebase Security Configuration

Copy and paste these security rules into your Firebase Realtime Database and Firebase Storage consoles so public users can only read published apps & increment downloads without tampering.

1. Realtime Database Security Rules

{
  "rules": {
    "apps": {
      ".read": true,
      "$appId": {
        // Only allow authenticated admin to write full document, or public to atomically increment downloadCount
        ".write": "auth != null || (newData.child('downloadCount').val() == data.child('downloadCount').val() + 1 && !newData.child('fileUrl').changed())"
      }
    }
  }
}

2. Firebase Storage Security Rules

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /apps/{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null || true; // Set auth requirement for production upload
    }
  }
}
